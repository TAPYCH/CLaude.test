# 🍊 Лана: Жизнь

Уютный симулятор жизни в духе The Sims, сделанный для Ланы: 19 лет, учится в Москве на зубного техника, а дома её ждёт солнечная Абхазия.

Это веб-игра, которая ставится на телефон как приложение (PWA) и работает без интернета. Всё нарисовано и написано с нуля: персонаж, 8 локаций, питомцы, 40+ вещей гардероба, музыка и звуки сделаны кодом (SVG, Canvas, WebAudio). Чужих картинок нет, поэтому нет и проблем с лицензиями, а стиль везде единый.

> Подробное ТЗ: [`docs/TZ.md`](docs/TZ.md)

## Как играть

- **Нажимай на светящиеся кружочки.** Это предметы и люди; появится меню действий, как в Sims.
- **Нажми на пол**, чтобы Лана туда пошла. Комнату можно листать пальцем.
- Внизу — **потребности**. Если кружочек краснеет, Лане что-то нужно.
- Кнопка с сердечком справа внизу — **телефон** с картой, гардеробом, заданиями и всем остальным.
- Часы вверху: ⏸ пауза, ▶ обычная скорость, ▶▶ быстрая.
- Фиолетовая плашка вверху — **текущее задание**. На нужном предмете появляется стрелка 👇.

## 💌 Персонализация

Открой [`js/config.js`](js/config.js):

```js
loverName: 'Любимый',      // как подписан любимый в чате
loveNotes: [ ... ],        // записки, которые приходят Лане каждый игровой день
finalLetter: '...',        // письмо, которое она прочитает после диплома
```

Впиши туда свои слова: она будет читать их в игре.

## 📲 Как отдать игру Лане

Игре нужен любой статический HTTPS-хостинг. Проще всего GitHub Pages:

1. На GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. После любого push workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) сам опубликует игру по адресу `https://<логин>.github.io/<репозиторий>/`.
3. Отправь ссылку Лане.
   - **iPhone:** открыть в Safari → «Поделиться» → «На экран Домой».
   - **Android:** открыть в Chrome → «Установить приложение» (или ⋮ → «Добавить на главный экран»).

После первой загрузки игра работает **без интернета**. Сохранение хранится на телефоне; в настройках можно скопировать код сохранения и перенести его на другое устройство.

Ещё варианты: Netlify Drop (перетащить папку на app.netlify.com/drop), Vercel, любой хостинг.

### Запуск у себя на компьютере

```bash
npx http-server -p 8080 -c-1 .
# или
python3 -m http.server 8080
```

Открыть http://localhost:8080. Игра работает только через веб-сервер: ES-модули не грузятся по `file://`.

## 🛠 Для разработчика

Без сборки и без зависимостей: чистые ES-модули.

```
index.html, manifest.webmanifest, sw.js
css/          style.css (дизайн-система), fonts.css
assets/fonts/ Nunito + Marck Script (OFL)
icons/        иконки PWA (генерируются)
js/
  main.js         запуск, главный цикл, уведомления
  game.js         время, потребности, действия, сон, поездки, магазин, питомцы
  config.js       💌 персонализация
  audio.js        процедурные звуки и музыка (WebAudio)
  core/           state (сохранения), progress (задания/награды/чаты), time, bus
  data/           items, actions, quests, achievements, contacts, places, scenes
  art/            character.js (Лана), hair.js, pets.js, palette.js, scenes/*.js
  ui/             world (сцена, камера), hud, menu, phone, wardrobe, cutscenes, modal, fx
  minigames/      framework + 7 игр
tools/          скриншоты, автотесты, генерация иконок и sw.js
docs/TZ.md      техническое задание
```

**После изменения файлов** пересобери список кеша для офлайна:

```bash
node tools/gen-sw.mjs        # обновляет sw.js (версия кеша = хеш файлов)
node tools/make-icons.mjs    # перерисовать иконки (нужен запущенный сервер на :8080)
```

**Отладка:** в консоли браузера доступен `__lana.S` — всё состояние игры (деньги, потребности, навыки…).
